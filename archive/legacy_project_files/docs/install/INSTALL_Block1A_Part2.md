# Install Block1A Part2

Packa upp ZIP-filen i projektets rot:

```text
C:\PyProjects\Taxa 3.0
```

Kör sedan:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Förväntat resultat:

```text
Avfallstaxa Parser 3.0 bootstrap OK
Config loaded: Avfallstaxa Parser 3.0 0.1.0
```

Git:

```bash
git add .
git commit -m "Parser3 Block1A Part2 Config and Utilities"
```

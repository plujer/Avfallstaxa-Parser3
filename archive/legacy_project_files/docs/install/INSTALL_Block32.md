# Install Block32 Cleanup + Parser v1.0 Candidate

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

Kör:

```bat
python -m pytest
build_report.bat
```

ZIP-filen för återrapportering finns därefter i:

```text
rapportzip/
```

Commit:

```bat
git add .
git commit -m "Parser3 Block32 Cleanup and Parser v1.0 Candidate"
git push
```

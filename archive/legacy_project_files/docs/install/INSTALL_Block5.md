# Install Block5 Validation Engine

Packa upp ZIP-filen i projektets rot:

```text
C:\PyProjects\Taxa 3.0
```

Verifiera:

```bat
.venv\Scripts\activate
python run.py
python -m pytest
```

Testa validering:

```bat
python run.py --validate
```

Git:

```bat
git add .
git commit -m "Parser3 Block5 Validation Engine"
git push
```

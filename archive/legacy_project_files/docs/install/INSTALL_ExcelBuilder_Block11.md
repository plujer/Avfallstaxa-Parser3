# Install Excel Builder Block 11 – EDP Export Isolation

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

## Kör tester

```bat
python -m pytest
```

## Bygg Sorsele

```bat
build_sorsele_excel.bat
```

## Bygg rapportpaket

```bat
build_excel_report.bat
```

## Skicka tillbaka

Skicka senaste ZIP-filen från:

```text
rapportzip/
```

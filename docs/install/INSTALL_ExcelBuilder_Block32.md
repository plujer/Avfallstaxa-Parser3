# Install Excel Builder Block 32 – v1.0 Specification

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

## Kontrollera specifikation

```bat
python tools\check_v1_spec.py
```

## Kör tester

```bat
python -m pytest
```

## Bygg rapportpaket

```bat
build_excel_report.bat
```

## Git commit

```bat
git commit -m "Excel Builder Block32 v1.0 Specification"
```

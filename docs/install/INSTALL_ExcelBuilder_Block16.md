# Install Excel Builder Block 16 – Write Suggestions and Trace

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

## Kör tester

```bat
python -m pytest
```

## Bygg rapportpaket

```bat
build_excel_report.bat
```

## Skicka tillbaka

Skicka senaste ZIP-filen från:

```text
rapportzip/
```

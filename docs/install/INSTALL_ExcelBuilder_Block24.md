# Install Excel Builder Block 24 – Workbook Schema Scanner

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

## Kontrollera testsyntax

```bat
python tools\check_test_syntax.py
```

## Kör tester

```bat
python -m pytest
```

## Bygg rapportpaket

```bat
build_excel_report.bat
```

## Skicka tillbaka

Skicka senaste ZIP-filen från:

```text
rapportzip/
```

## Git add

```bat
git add .
```

```bat
git commit -m "Excel Builder Block24 Workbook Schema Scanner"
```

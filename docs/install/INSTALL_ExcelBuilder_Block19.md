# Install Excel Builder Block 19 – Template Master Versioning

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

## Kör tester

```bat
python -m pytest
```

## Testa template-kopia

```bat
build_template_copy.bat
```

## Bygg rapportpaket

```bat
build_excel_report.bat
```

## Skicka tillbaka

Skicka senaste ZIP-filen från:

```text
rapportzip/
```

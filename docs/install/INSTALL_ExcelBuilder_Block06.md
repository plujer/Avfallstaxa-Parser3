# Install Excel Builder Block 06 – Report Package Standard

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

Kör:

```bat
python -m pytest
build_excel_report.bat
```

Skicka senaste ZIP-filen från:

```text
rapportzip/
```

Commit:

```bat
git add .
git commit -m "Excel Builder Block06 Report Package Standard"
git push
```

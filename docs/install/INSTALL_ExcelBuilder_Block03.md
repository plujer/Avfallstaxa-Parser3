# Install Excel Builder Block 03

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

Kör:

```bat
python -m pytest
build_excel_report.bat
```

Skicka sedan senaste ZIP-filen från:

```text
rapportzip/
```

Commit:

```bat
git add .
git commit -m "Excel Builder Block03 Report ZIP and Workbook Snapshot"
git push
```

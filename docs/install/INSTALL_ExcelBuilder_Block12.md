# Install Excel Builder Block 12 – Project Isolation Architecture

Packa upp ZIP-filen i projektets rot och ersätt befintliga filer.

## Kör tester

```bat
python -m pytest
```

## Kör Sorsele-projektet

```bat
build_sorsele_project.bat
```

## Bygg rapportpaket

```bat
build_excel_report.bat
```

## Skicka tillbaka

Skicka senaste ZIP-filen från:

```text
rapportzip/
```

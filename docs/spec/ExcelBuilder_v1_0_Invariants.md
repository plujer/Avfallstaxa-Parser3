# Excel Builder v1.0 – regler som aldrig får brytas

## EDP-regler

```text
Taxa_från_edp får inte ändras automatiskt.
Befintliga taxekoder i EDP är fasta.
Standardtaxor får inte skriva över kommunens taxor.
```

## Kommunisolering

```text
Sorsele får inte använda Malås EDP-export.
Malå får inte använda Norsjös EDP-export.
Norsjö får inte använda Sorseles EDP-export.
```

## Masterregler

```text
Masterarbetsboken får inte ändras direkt.
Ny masterversion kräver godkännande.
Master ska versionsnamnges.
```

## Rapportregler

```text
Efter varje block ska rapportzip skapas.
Rapportzip ska innehålla tester, beslut, schema och relevanta arbetsböcker.
```

## Beslutsregler

```text
Rubriker ska inte klassas som NEW_TAXA.
Osäkra kandidater ska bli REVIEW_REQUIRED.
Toppkandidater nära varandra ska bli REVIEW_REQUIRED.
Beslut ska ha motivering.
```

## Kunskapsregler

```text
Generell kunskap får delas.
Kommununik data får inte delas.
Inlärda regler ska versioneras.
```

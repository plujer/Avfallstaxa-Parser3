# Git Workflow

## Första repo

```bash
git init
git add .
git commit -m "Initial Parser3 Bootstrap"
```

## Rekommenderade grenar

```bash
git checkout -b parser-v3
git checkout -b feature/block-1a
```

## Commit per blockdel

```bash
git add .
git commit -m "Parser3 Block1A Part2 Config and Utilities"
```

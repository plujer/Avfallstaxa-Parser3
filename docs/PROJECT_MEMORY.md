# PROJECT_MEMORY

Detta dokument beskriver HUR projektet drivs.

## Arbetscykel (obligatorisk)

1. Installera nästa block.
2. Kör:
   - python tools\check_v1_spec.py
   - python -m pytest
   - build_excel_report.bat
3. Ladda upp senaste rapportzip i ChatGPT.
4. ChatGPT analyserar rapporten.
5. Nästa block tas fram.
6. Uppdatera dokumentation.
7. Git commit.
8. Git push.

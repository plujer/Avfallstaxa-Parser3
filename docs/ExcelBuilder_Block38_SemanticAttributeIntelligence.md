# Block38 – Semantic Attribute Intelligence

Block38 extraherar konservativa semantiska attribut ur taxetext och stödtext.

Attribut:

- material
- avfallstyp
- enhet
- behållartyp
- hämtningsintervall
- fastighetstyp

Steget används som beslutsstöd inför senare ranking och decision engine. `Taxa_från_edp` är fortsatt facit och ändras inte automatiskt.
